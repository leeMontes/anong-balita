ANONG BALITA?
RADIO INFO

OPERATOR'S MANUAL

MODEL AB-7 · BALITA BAND TRANSCEIVER

1. WHAT IS THIS?

Anong Balita? ("What's the news?") is a pocket walkie talkie that runs entirely in your web browser. Spin up a channel called a Balita Group, hand out the code or QR, and everybody who tunes in can talk to each other push-to-talk.

2. STARTING A BALITA GROUP

  1. On the RADIO page choose CREATE.
  2. Type a Balita Group Name (e.g. TONDO PATROL) and your handle.
  3. Hit BROADCAST. You become the base station and get a 5-character code plus a QR.
  4. Share the code or let people scan the QR. They land straight on the channel.

3. TUNING IN

  1. Choose JOIN, enter the 5-character code and a handle, then TUNE IN.
  2. Or scan the QR — the code fills in for you.

4. PUSH TO TALK

Hold the big red PUSH TO TALK button — or hold the SPACE bar — to transmit. Release to listen. A roger beep confirms you're off the air. The OPS counter shows how many units are connected to the channel.

5. BACKGROUND / SCREEN OFF

This app asks the browser to keep the radio alive so you keep receiving audio when the tab is hidden or the phone is idle. On supported browsers (desktop and Android) audio keeps flowing in the background. On iOS Safari, Apple suspends background web audio, so receiving may pause when the app is fully minimized — that's a platform limit, not a bug.

6. WHERE IS MY DATA SAVED?

Short answer: it isn't. There is no database and no recording.

  • Voice audio travels peer-to-peer over encrypted WebRTC. It is mixed live on the base station and passed on. Nothing is recorded or stored.
  • Signaling uses the public PeerJS cloud server only to introduce two browsers to each other. No audio or messages are stored there.
  • QR codes are drawn locally in your browser. No image is uploaded anywhere.
  • Group name, handles and code live in memory for the duration of the call and vanish when you end the channel.
  • No accounts, no cookies, no analytics, no tracking.

7. NOTES & LIMITS

  • The base station must stay connected. If the host leaves, the channel closes.
  • The more units connected, the more the base station's connection carries. It scales, but a phone on a weak line has limits.
  • Mic access is required — grant it when asked.
  • Everyone on the same code hears each other. Don't share a code you don't trust.
